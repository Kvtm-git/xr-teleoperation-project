# Afsluttende Projekt – XR Teleoperation

## Formål
Undersøge XR-baseret teleoperation med fokus på opsætning, styring og dataindsamling.

## Setup
- Ubuntu 22.04
- MetaQuest 3 VR Headset
- VS Code
- Conda
- xr_teleoperate
- unitree_sdk2_python

## Mappestruktur
- repos/
- notes/
- docs/
- scripts/
- data/

## Arbejdsgang
1. Start simulation
2. Start xr_teleoperate
3. Forbind headset
4. Test styring
5. Optag data
6. Dokumentér resultater
